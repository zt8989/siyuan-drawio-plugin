# 02 — 思考中 UI

**What to build:** 去掉原来的“加载中”，流式返回带思考内容时显示灰色字体“思考中 abcd...”（abcd 即思考内容，过长用 ... 省略，换行自动更新 abcd...）；正文按正常样式显示。

**Blocked by:** 01 — 流式传输 tracer-bullet（需要其传递的思考增量事件）。

**Status:** ready-for-agent

- [ ] 有思考流时显示灰色“思考中 abcd...”，无思考时不出现该行
- [ ] 思考文本过长用 ... 省略，换行时自动更新显示内容
- [ ] 正文（非思考）按正常样式显示，不受灰色思考样式影响
- [ ] 思考结束后思考行收起或转为完成态，不残留占位
